# BotStrike 与 CS:GO 的完整差距评估

评估基于当前仓库和本次 hybrid animation PR，日期 2026-11-02。参照对象是历史 CS:GO 的完整产品体验；CS2 的新特性应单独立项。下列差距和优先级是工程判断，尚无真人盲测数据，因此不提供“达到 CS:GO 的百分之多少”这样的评分。

BotStrike 已有能闭环的多人射击、原生权威模拟、机器人、经济与目标模式，以及可验证的比赛记录。距离成熟竞技射击产品，最大的工作仍在枪法学习曲线、地图与碰撞、网络公平性、声音信息、真人对战规模和长期运营。本次动画 PR 解决其中的角色动作合成，其他项目需要各自的规则、验证和内容预算。

## 建议执行次序

1. **完成本动画 PR 的真实验收**：数字/生命周期/回放回归、实际桌面与 Android、前后录像、真人动作和操作感；要求表中的外部门槛保持可见。
2. **一个可靠的竞技垂直切片**：一张可验证的地图、精确且可学习的武器/移动、可信音频、完整经济与回合异常处理、跨网络公平测试。
3. **组织真人 5v5**：记录命中争议、死因理解、路线与攻防平衡、操作舒适度、完成率；以证据决定调整。
4. **多人服务和留存**：地区/匹配/排名、举报复核、观战复盘、恢复与容量；使用真实玩家规模设门槛。
5. **扩内容与生态**：地图、武器、训练、社区工具和活动，建立持续内容生产与评审流程。

涉及移动、散布、碰撞、经济或胜负条件的后续改动，应同步 native/browser 回放，并使用精确的新 application profile。旧签名存档继续按其原规则解释。动画表现、输入设置和 UI 改进则需保持规则边界。


## 触控板同时移动与瞄准的线索

本次只读检查中，这台 GNOME 机器的 `org.gnome.desktop.peripherals.touchpad disable-while-typing` 为 `true`。libinput 的[官方说明](https://wayland.freedesktop.org/libinput/doc/latest/palm-detection.html#disable-while-typing)确认，该功能会在按键后暂时抑制触控板移动，且打字期间开始的触摸可能持续不控制指针。这是“按住移动键时无法瞄准”的一个具体候选原因，尚未通过实体触控板的事件记录确认。

游戏里的键盘移动和指针瞄准分别处理，增加动画插值无法补回操作系统未送达的位移。验收时应在同一台笔记本记录“只移动触控板”和“按住 W 同时移动触控板”的浏览器 pointer 事件，并在操作系统设置中临时关闭打字抑制后重复比较。页面内需提供清晰的控制说明和鼠标/手柄等可用选择；本 PR 没有修改用户的系统设置，也没有把合成浏览器事件当成实体触控板验收。
