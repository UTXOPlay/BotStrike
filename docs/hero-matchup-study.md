# Hero selection and matchup study (#20)

Status: V5 selection implementation and native baseline; **zero human duels or
matches** in this evidence package. No pick-rate, win-rate or balance conclusion
is available. No numeric hero HP/speed/cooldown change is proposed here.

Tactical requires one chassis per squad, selected before all ten READY players
start and locked through halftime. Native validation rejects duplicates/AI; native
steps ignore later hero input. Casual allows its existing buy/reboot selection
windows but changing chassis cannot restore HP, armor, cooldown or inventory.
The 36 ordered changes are covered by the native selection exploit test.
