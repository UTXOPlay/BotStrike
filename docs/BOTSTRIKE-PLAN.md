# BotStrike scope

2050 cyberpunk robot tactical FPS by Arthur Zhang, published by UTXOPlay Labs. Independent repository and history, with no legacy engine, game assets or vendor tree.

Six distinct chassis and native skills; three authored map layouts; 5v5 human/AI rooms; public queue, private invites and practice; complete deathmatch respawn and demolition economy/objectives; twelve weapons and twelve equipment systems with native effects. Signed host replay binds the exact engine and arsenal-v2 input schema. Myelin is off-chain host replay, not CKB settlement.

The entire picture fills the viewport. All HUD and controls stay inside it; mobile supports simultaneous movement, aiming and firing. Validate 1920×1080, 2560×1080, 2560×1440, 3840×2160, 390×844 and 844×390. Bound backing pixels, cache scenery, release replaced GPU resources and respect reduced motion.

Models, previews and carried weapons share the real gameplay meshes. Cover art guides the industrial robot silhouettes, materials, skyline and cyan/amber lighting. Record actual rendered evidence and do not confuse promotional imagery with real-time screenshots.
